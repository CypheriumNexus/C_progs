## 📖 About This Repository

<details open>
<summary><strong>Repository Overview</strong></summary>

A collection of C programming assignments, exercises, and practical projects developed during **CPT 234 – C Programming I**.

This repository documents the application of fundamental programming principles through hands-on coursework, emphasizing structured programming, logical problem-solving, algorithm development, and source-code implementation.

Programs were developed using **Microsoft Visual Studio 2019**, utilizing its development environment, project configuration, debugging capabilities, and Microsoft C compiler.

The repository serves as an educational reference and a record of programming experience gained throughout the course.

## ⚙️ Building & Executing Programs

<details>
<summary><strong>Visual Studio 2019 — Execution Workflow</strong></summary>

1. Clone or download the repository.
2. Launch Microsoft Visual Studio 2019.
3. Open the applicable solution or project file (`.sln` / `.vcxproj`), if provided.
4. Alternatively, create a new C Console Application and add the desired `.c` source file.
5. Verify the project configuration and compiler settings.
6. Build the application using **Build Solution**.
7. Execute the compiled program using **Start Without Debugging** or the debugger.
8. Review program output and troubleshoot any compiler or runtime errors.

**Important:** Individual source files may require their own project configuration. Ensure the project is configured to compile as C rather than C++ where applicable.

</details>
